## Purpose

This repository documents the process of the CVDS university course, focusing on learning technologies and developing a collaborative project. It includes laboratoriesm exercises, exams, and a record of the first project developed during the semester.
It is shared publicly for reference and educational purposes only.

Feel free to explore and use any of the resources here for non-commercial and educational purposes. If you find something useful, you're welcome to reference it in your own learning journey.

</br>
</br>

## :books: Labs for Learning Technologies

The first three labs are dedicated to learning various technologies relevant to the course.
- Lab 1: Introduction to Git.
- Lab 2: Introduction and implementation of SpringBoot & Maven.
- Lab 3: Advanced practice with SpringBoot & Maven, using desing patterns.

</br>

## 🚀 Project Development

From Lab 4 to Lab 7, the course focuses on the development of a complete project.
The final version of the project is hosted in a separate repository, available here (https://github.com/Andr3xDev/ISIBook and https://github.com/daviespr1406/Reservas_SysGuiReact/tree/develop).
- Lab 4: Scaffolding, planning and mockups.
- Lab 5: Initial interface, database connection, backend modeling.
- Lab 6: Backend completion, CI-CD addition, frontend almost finished.
- Lab 7: Pre-final version, functional with the graphical interface..

</br>

## 🤝 Working in Large Groups
Lab 8 involves a deliverable that simulates working in teams of 20 or more people, emphasizing collaboration and large-scale project management. We only did documentation of all temporal final project.

</br>

## 📝 Exams

The exams are designed to assess my individual technical skills, not those of my teammates. Each exam was designed to ensure that the student was not dependent on others and had full knowledge of the subject matter.
- Lab 1: Use Maven, SpringBoot and pattern desings to create a little app without REST.
- Lab 2: Little REST app with deploy and basic interfaz with React.
